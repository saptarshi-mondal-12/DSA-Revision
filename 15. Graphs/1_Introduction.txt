Q. What is a graph data structure?

A graph is a non-linear data structure consisting of nodes that have data and are connected to other nodes through edges.

Nodes are circles represented by numbers. Nodes are also referred to as vertices. They store the data. The numbering of the nodes can be done in any order, no specific order needs to be followed.

   (1)─────(4)
    |       | <------------- Edge
    |       |
   (2)─────(5) <------------ Nodes
    \       /
     \     /
       (3)

Two nodes are connected by a horizontal line called Edge. Edge can be directed or undirected. Basically, pairs of vertices are called edges.

In the above example, the edge can go from 1 to 4 or from 4 to 1, i.e. a bidirectional edge can be in both directions, hence called an undirected edge. Thus, the pairs (1,4) and (4,1) represent the same edge.

✅ Types of Graphs:

1. Directed vs Undirected
   • Directed: Edges have a direction (e.g., A → B).
   • Undirected: Edges have no direction (e.g., A — B).

 
2. Weighted vs Unweighted:
   • Weighted Graph: Edges carry weights or costs.
   • Unweighted Graph: Edges do not have weights.


3. Cyclic vs Acyclic:
   • Cyclic Graph: Contains at least one cycle.
   • Acyclic Graph: No cycles.


4. Connected vs Disconnected:
   • Connected Graph: Every node is reachable from any other node.
   • Disconnected Graph: Some nodes are not connected.

✅ --------------------------------Algorithms:---------------------------------

➖1. Dijkstra Algorithm: 
Dijkstra's algorithm is a single source shortest path algorithm used to find the minimum distance from a source node to all other nodes in a weighted

Limitations of Dijkstra's Algorithm: 
   1. Does Not Work with Negative Edge Weights. (Dijkstra's algorithm fails to minimize the distance, keeps on running, and goes into an infinite loop. As a result it gives TLE error).
   2. Works only on Single Source.

Time complexity: O((V+E)Log V) ~ (E log V)
Space complexity: O(E + V)



➖2. Bellman-Ford Algorithm:
The Bellman-Ford algorithm is a single-source shortest path algorithm, like Dijkstra’s, but it can handle graphs with negative edge weights. It is especially useful when such edges are present and when detecting negative weight cycles is important.

Key Features:
   1. Works on directed or undirected graphs.
   2. Handles negative weights.
   3. Can detect negative weight cycles.

Real World Applications of Floyd-Warshall Algorithm:
   1. In computer networking, the algorithm can be used to find the shortest path between all pairs of nodes in a network. This is termed as network routing.

   2. Flight Connectivity In the aviation industry to find the shortest path between the airports.

   3. GIS(Geographic Information Systems) applications often involve analyzing spatial data, such as road networks, to find the shortest paths between locations.

Time complexity: O(N x E)
Space complexity: O(N) 


➖3. Floyd Warshall Algorithm: 
The Floyd Warshall algorithm is a multi-source shortest path algorithm that helps find the shortest distances between all pairs of nodes in a graph. It works by repeatedly improving the path between every pair of nodes, checking if going through another node gives a shorter route. 

It also helps to detect negative cycles as well. 

In Floyd Warshall's algorithm, we need to check every possible path going via each possible node. And after checking every possible path, we will figure out the shortest path(a kind of brute force approach to find the shortest path).

Floyd Warshall Algorithm is not possible for ngative cycle (if it exist). because each iteration it reduces.


Time complexity: O(V^3)
Space complexity: O(1)
