Destructor

Copy constructor

Copy assignment operator

3. Difference between stack and heap memory in C++?
Answer:

Stack: Fast, auto-managed, limited size.

Heap: Large, manually managed (using new/delete), slower access.

4. What is RAII (Resource Acquisition Is Initialization)?
Answer:
It is a C++ technique where resource allocation is tied to object lifetime. When the object goes out of scope, the destructor releases resources.

The vtable is a table of function pointers created for classes with virtual functions.

Each object has a hidden vptr that points to its class's vtable.

Answer:
The base class version of the virtual function is called. The derived part isn’t yet constructed.

Q1: What are the main differences between pointers and references in C++?
A: Pointers can be reassigned and can be null; references are aliases and cannot be null or reassigned. Syntax: * for pointer, & for reference.

Q2: Explain the difference between stack and heap memory.
A: Stack is for static allocation with automatic lifetime, fast access, limited size. Heap is for dynamic allocation with manual management via new/delete, larger but slower.

Q3: What are smart pointers? Name types and use cases.
A: Smart pointers automate memory management.
- unique_ptr: sole ownership
- shared_ptr: shared ownership with ref counting
- weak_ptr: non-owning observer to avoid cycles

Q4: How does exception handling work in C++? What keywords are used?
A: try contains code that might throw, throw raises exception, catch handles it. Stack unwinding calls destructors.

Q5: What is the difference between new/delete and malloc/free?
A: new/delete are C++ operators that call constructors/destructors; malloc/free are C functions allocating raw memory without initialization.

Q6: Describe time complexities of STL containers like vector, map, unordered_map, set.
A: vector: O(1) access, O(1) amortized push_back, O(n) insert/delete arbitrary
map: O(log n) insert/find/erase
unordered_map: O(1) average, O(n) worst insert/find/erase
set: O(log n) insert/find/erase

Q7: What is RAII? Why is it important?
A: Resource Acquisition Is Initialization ties resource lifetime to object lifetime to prevent leaks.

Q8: Explain deep copy vs shallow copy.
A: Shallow copy copies pointers causing shared ownership. Deep copy duplicates pointed data.

Q9: How does virtual function dispatch work?
A: Via vtable, a runtime table of function pointers, ensuring polymorphic calls.

Q10: What’s the difference between compile-time and run-time?
A: Compile-time is during compilation (templates, constexpr), run-time during execution (dynamic memory, virtual calls, exceptions).
